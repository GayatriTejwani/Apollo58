# Archive

Early test builds, kept for reference. We don't have source code for these. Most were built with QMK's online configurator or from the stock Lily58 keymaps, before Apollo58 had its own firmware.

| File | What it is |
|---|---|
| `lily58-stock-default-oled.hex` | QMK's stock Lily58 default keymap, with the stock OLED screens |
| `lily58-stock-via-oled.hex` | QMK's stock Lily58 VIA keymap, with OLED |
| `layout-test-2026-10-06.hex` | A layout test from 6 Oct 2026 |
| `apollo58-early-prototype.hex` | An early Apollo58 build that predates [`oled-themes/first-apollo58`](../oled-themes/first-apollo58/) |

**For everyday use, flash [`firmware/apollo58/apollo58-v1.3.0.hex`](../firmware/apollo58/apollo58-v1.3.0.hex).**
